# Лабораторная работа № 3. Создание сервиса предсказаний

# 1. Использование модели из ЛР № 2

В предыдущей лабораторной проводились эксперименты с регрессионными моделями для оценки стоимости автомобиля. Для сервиса используется выбранная модель из MLflow; конкретный `run_id` задаётся в `services/models/get_model.py`.

Файл `get_model.py` выполняет следующие действия:

1. Подключается к MLflow Tracking Server по настроенному адресу.
2. Загружает артефакт модели по идентификатору запуска (`run_id`) и пути артефакта.
3. Сериализует модель в `services/models/model.pkl`.

Для выгрузки модели из корня проекта:

```bash
source .venv_my_proj/bin/activate
python services/models/get_model.py
```
Перед запуском должны быть доступны MLflow и фактический `run_id` модели. Порт MLflow и путь артефакта проверяются в настройках проекта

Файл `model.pkl` обычно не включается в Git: его получают из MLflow на машине, где запускается приложение.

# Запуск ЛР3

В терминале выполнить
git clone <URL_РЕПОЗИТОРИЯ> my_proj
cd my_proj

Файл модели не включен в git-репозиторий, его нужно получить отдельно с помощью get_model.py

1 Создать виртуальное окружение
2 Проверить адрес MLflow в get_model.py
3 Указать действительный run_id обученной модели и путь её артефакта
4 Запустить скрипт
python services/model/get_model.py

В директории services/models/ должен появиться файл model.pkl

Сборка Docker образа

cd services/ml_service

sudo docker build -t car-price-service:1 .
sudo docker images

sudo docker run --rm\
 --name car-price-service\
 -p 8001:8000\
 -v "$(pwd)/../models:/models:ro"\
 car-price-service:1

 После запуска FastAPI должен стать доступен по адресу 
 http://localhost:8001

 Проверка работоспособности

 открыть
 http://localhost:8001/docs

 Указать id и вставить в тело запроса
 ```json
{
  "Car_Name": "swift",
  "Year": 2018,
  "Selling_type": "Dealer",
  "Present_Price": 6.5,
  "Driven_kms": 45000,
  "Fuel_Type": "Petrol",
  "Transmission": "Manual",
  "Owner": 0,
  "Car_Age": 8
}
```
Нажать Execute

При корректной работе сервер возвращает HTTP-статус 200 и JSON следубщей структуры:

```json
{
  "item_id": 123,
  "price": 6.3
}
```

Для остановки нажать Ctrl+C или ввести команду

sudo docker stop car-price-service
